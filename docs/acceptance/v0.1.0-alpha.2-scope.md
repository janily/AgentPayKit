# AgentPayKit v0.1.0-alpha.2 release scope

Status: Developer Preview only.

This release supersedes `0.1.0-alpha.1` and fixes first-time Vercel deployments
by loading `.env.local` and forwarding the public Base Sepolia receiver to the
deployment's build and runtime environments.

The supported payment path remains:

- Base Sepolia only;
- fixed USDC pricing per Endpoint;
- synchronous JSON request/response;
- manual wallet confirmation for every paid call.

Not included in this release:

- Base Mainnet support;
- dynamic, token, or time-based pricing;
- subscriptions or asynchronous jobs;
- automatic payment retries or autonomous wallet signing;
- marketplace or no-code publishing flows.

The three publishable packages in this scope are:

- `@agentpaykit/server`
- `@agentpaykit/cli`
- `create-agentpay-skill`

All three packages target the `0.1.0-alpha.2` pre-release line.
