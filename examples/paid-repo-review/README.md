# `paid-repo-review`

A paid Next.js Skill generated by AgentPayKit.

## Configure

Create `.env.local` from `.env.example` and set a dedicated low-value Base
Sepolia receiver. The project refuses to start or build without it.

```bash
cp .env.example .env.local
```

## Develop

```bash
pnpm dev
```

`GET /api/health` is unpaid. The generated `SKILL.md` documents the paid
`/api/invoke` Endpoint, and `examples/input.json` contains a stable test input.

## Verify

```bash
pnpm verify
```

Deploy with `pnpm deploy` only after verification. Record the deployed Endpoint,
commit SHA, receiver, fixed `0.01 USDC` price, and Base Sepolia acceptance
evidence before publishing the generated Skill instructions.
