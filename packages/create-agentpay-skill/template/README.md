# `__PROJECT_NAME__`

A paid Next.js Skill generated by AgentPayKit.

## Configure

Install dependencies, create a local environment file, and set a dedicated
low-value Base Sepolia receiver address. Never use a private key, seed phrase,
or high-value wallet in this project.

```bash
pnpm install
cp .env.example .env.local
```

Update `agentpay.skill.ts` with the fixed test price and schema. Keep business
logic in `src/review-repository.ts`. The project intentionally fails to start or
build while `AGENTPAY_RECEIVER_ADDRESS` is missing.

## Develop

```bash
pnpm verify
pnpm dev
```

`GET /api/health` returns an unpaid health response. Send `examples/input.json`
to `http://localhost:3000/api/invoke`; an unsigned valid request returns
`402 Payment Required`. Business logic can be checked with `pnpm test` without
opening a wallet.

## Deploy

Install the Vercel CLI credentials for your account, then run:

```bash
pnpm deploy
```

Deployment runs tests, type checking, a production build, one Vercel production
deployment, and an online quote check. It writes the verified Agent instructions
to `skill/SKILL.md`. The preview supports Base Sepolia, fixed USDC pricing,
synchronous JSON, and a fresh human MetaMask confirmation for every payment.
